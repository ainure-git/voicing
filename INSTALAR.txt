========================================
  VOICING - INSTALACION
========================================

Escucha la terminal (y dicta en ella) en Cursor / VS Code / Windsurf.
Instalacion sencilla (no necesitas conocimientos tecnicos):

1. Abre tu editor (Cursor, VS Code, Windsurf...).

2. Pulsa a la vez:  Ctrl  +  Mayus (Shift)  +  P

3. Escribe:  Install from VSIX
   y elige la opcion  "Extensions: Install from VSIX..."

4. Selecciona el archivo:
       voicing-<version>.vsix
   (esta en esta misma carpeta)

5. Cuando te lo pida, pulsa  "Reload"  (Recargar la ventana).
   *** Este paso de recargar es IMPRESCINDIBLE ***

----------------------------------------
 SI PREFIERES EL INSTALADOR AUTOMATICO
----------------------------------------
Haz doble clic en:  INSTALAR_EN_CURSOR.bat
(Funciona si tienes el comando "cursor" disponible. Si no,
 usa los pasos 1-5 de arriba, que siempre funcionan.)

O, mas facil todavia, abre PowerShell y pega:
  irm https://raw.githubusercontent.com/ainure-git/voicing/main/scripts/install.ps1 | iex

----------------------------------------
 DONDE ESTAN LOS CONTROLES
----------------------------------------
  - Barra inferior derecha (junto a la campana): iconos de
    microfono y altavoz.
  - Ctrl+Shift+P y escribe "Voicing".
  - Clic derecho dentro de la terminal.

----------------------------------------
 COMO ESCUCHAR (lo mas fiable)
----------------------------------------
  1) Selecciona texto con el raton en la terminal.
  2) CLIC DERECHO dentro de la terminal ->
     "Voicing: Read selection".

  Alternativa que siempre funciona:
     Selecciona -> Ctrl+C -> pulsa el altavoz
     (o "Voicing: Read clipboard").

  Nota: pulsar el icono del altavoz directamente puede perder
  la seleccion (es un limite de VS Code); por eso se recomienda
  el clic derecho o copiar con Ctrl+C.

----------------------------------------
 VELOCIDAD Y VOZ
----------------------------------------
  - Velocidad: Ajustes -> busca "Voicing" -> "rate" (2.0 = doble).
  - Voz: Ctrl+Shift+P -> "Voicing: Show available voices".
  - Probar: "Voicing: Test voice".
  - Sin voz en espanol (Windows)? Configuracion de Windows ->
    Hora e idioma -> Voz -> anade una voz espanola y eligela.

----------------------------------------
 DICTAR (MICROFONO)
----------------------------------------
  El microfono usa el dictado nativo del editor si existe; si no,
  inserta "/voice tap" (el dictado de Claude Code).
  => El microfono solo es util si usas Claude Code.
     El ALTAVOZ funciona siempre.

----------------------------------------
 PRIVACIDAD
----------------------------------------
  Todo funciona en tu ordenador. No se envia nada a Internet.
  Sin nube, sin claves, sin telemetria.

Si algo no funciona, abre TROUBLESHOOTING.md.
